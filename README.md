# DropSync-Timer
Ziel ist eine native Android-App (Kotlin, Jetpack Compose), die Workout-Timer über Sprachansagen (TTS) legt, ohne die Musik zu stoppen. Das Alleinstellungsmerkmal ist der "Drop-Sync-Modus": Die App synchronisiert das Ende des Workout-Countdowns perfekt mit dem Drop eines lokal abgespielten Songs (via Poweramp).
